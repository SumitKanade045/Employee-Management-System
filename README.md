# Employee Management System

## Project Overview
The Employee Management System is a console-based Java application used to manage employee records. It allows users to add, view, sort, and delete employee details.

## Technologies Used
- Core Java
- Object-Oriented Programming (OOP)
- Collections Framework
- ArrayList and TreeSet
- Comparator and Lambda Expressions
- Exception Handling

## Features
1. Add employee details.
2. View all employee records.
3. Sort employees by ID.
4. Sort employees by name.
5. Sort employees by age.
6. Sort employees by mobile number.
7. Sort employees by salary.
8. Delete a specific employee using their ID.
9. Delete all employee records.

## Employee Attributes
- Employee ID
- Employee Name
- Employee Salary
- Mobile Number
- Age

## How to Run
1. Clone or download the project.
2. Open the project in Eclipse, IntelliJ IDEA, or VS Code.
3. Compile the Java source files.
4. Run `TestUI.java`.
5. Use the console menu to manage employee records.

## Learning Outcomes
This project demonstrates practical use of Java OOP concepts, interfaces, collections, sorting techniques, lambda expressions, and exception handling.
